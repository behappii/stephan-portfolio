# Violet Aero

Дизайн-система сайта-портфолио веб-разработчика, собранная из макета главной страницы. Стиль — Frutiger Aero в фиолетовой гамме: светлое лавандовое «небо», матовое стекло, глянцевые кнопки с линией блика, мыльные пузыри. Настроение — оптимистичное и немного ностальгическое: Windows Vista и ранние iPhone, но в сегодняшней вёрстке.

## Голос

Портфолио говорит от первого лица, коротко и по делу.

- Делайте: глагол в начале («Проектирую интерфейсы в Figma», «Упаковываю в Docker»), конкретные технологии по именам, одна мысль на фразу.
- Не делайте: превосходные степени, выдуманные цифры и отзывы, эмодзи, восклицательные знаки.
- Чего пока нет — в квадратных скобках: `[Название проекта]`, `[год]`, `[you@email.com]`. Заглушка видна сразу, и её не спутать с настоящим фактом.
- Заголовки — короткие фразы без точки: «Избранные работы», «От макета до контейнера».

## Цвет

Одна тема, `aero`. Фон — вертикальный градиент неба: `sky-50` → `sky-300` → `sky-100` → `sky-200`; первый экран насыщеннее (сверху `sky-400`) и с белым свечением. Финальный раздел — «вечернее небо» `.va-dusk`: `violet-600` → `violet-800` → `dusk`, текст `on-violet`.

- Текст: заголовки `ink`, абзацы `ink-body`, подписи `ink-muted`, меню `ink-nav`. Все проходят 4.5:1 на любом тоне неба; `ink-muted` — самый светлый допустимый.
- Акцент: `violet-600` — метки разделов и акцентный текст; `violet-700` — ссылки; `violet-800` — обводки глянцевых элементов.
- Градиентный текст (`.va-gradient-text`, `violet-500` → `violet-800`) — только в заголовках от 24px: его верхний тон даёт 3.7:1.
- Глянец собирается из четырёх тонов `violet-gloss-*` с жёсткой границей на 50–51%: светлая верхняя половина, тёмная нижняя. Именно эта ступенька и читается как блик.

## Типографика

Два семейства Google Fonts, оба с кириллицей.

- **Nunito** (`--font-display`) — заголовки, кнопки, имя. Округлый, жирный (800–900), с лёгким отрицательным трекингом: отвечает за «мягкий пластик» Aero. Кнопки набраны тем же начертанием, что и главный заголовок.
- **Open Sans** (`--font-body`) — текст, теги, меню. Гуманистический гротеск, близкий к Frutiger по духу.

Крупные заголовки на вебе масштабируются через `clamp()`: значения стилей в токенах — верхняя граница.

## Поверхности

Три материала, и у каждого своя роль:

1. **Стекло** (`GlassCard`, `GlassNav`) — всё, что содержит текст: карточки, навигация. Белый градиент, белая кромка, `backdrop-filter: blur(blur-glass)`, тень `shadow-glass`. Работает только поверх неба.
2. **Глянец** (`GlossButton`, `IconTile`, `Orb`, бейдж `Tag tone="violet"`) — то, на что нажимают или что обозначает. Тёмная обводка `violet-800`, блик сверху, цветная тень.
3. **Пузыри** (`Bubble`) — только атмосфера. От трёх до пяти на экран, по краям, никогда поверх текста.

Без левых цветных полос у карточек и без плоских серых заливок: если элементу нужна граница — это белая стеклянная кромка.

## Разметка

Контейнер `max-width: 1240px`, поля `space-8` (32px). Разделы — `space-24` (96px) по вертикали, первый экран и контакты просторнее (`space-32`). Шапка раздела отстоит от содержимого на `space-12`. Сетки — `repeat(auto-fit, minmax(min(<колонка>px, 100%), 1fr))`, чтобы на телефоне всё складывалось в одну колонку. Скругления растут с размером: 16px у плиток, 24px у узких карточек, 28px у широких, «пилюля» у всего, что нажимается.

## Иконки

Линейные, 24×24, обводка 1.9, скруглённые концы (`Icon`, группа ассетов Icons). Внутри глянцевой плитки — белые, в тексте — `violet-800`. Технологию называет тег с её именем, а не чужой логотип.

## Фокус и доступность

В исходном макете не было состояния фокуса — система добавляет `focus-ring` (белый зазор и кольцо `violet-600`). Всё, что нажимается, не ниже 44px. Пузыри, окна-мокапы и шары-логотипы помечены `aria-hidden`.

## Подключение

Компоненты — `components/bundle.js`, глобальный объект `window.VioletAero`, нужен React 18. Стили — `components/bundle.css` поверх `tokens.css`; шрифты он подключает сам из Google Fonts. Тот же вид можно получить без React: классы `.va-*` в `bundle.css` описывают каждый элемент.

## Состав экспорта

| Папка / файл | Что внутри |
| --- | --- |
| `preview.html` | Все компоненты на одной странице: откройте в браузере, чтобы посмотреть систему вживую (React грузится с unpkg). |
| `tokens/tokens.json` | Токены как данные: цвета, шрифты, стили текста, отступы, скругления, тени, размытие. |
| `tokens/tokens.css` | Те же токены как CSS-переменные (`--violet-600`, `--space-8`, `--shadow-glass`…) и классы стилей текста (`.display-l`, `.lead`…). Подключает шрифты из Google Fonts. |
| `tokens/tailwind.preset.js` | Пресет Tailwind CSS поверх переменных из `tokens.css`: `bg-sky-100`, `text-ink`, `rounded-pill`, `shadow-glass`, `font-display`… |
| `components/bundle.js` | 13 React-компонентов, глобальный объект `window.VioletAero`. Нужен React 18. |
| `components/bundle.css` | Стили компонентов — классы `.va-*`, ими можно пользоваться и без React. |
| `components/index.d.ts` | Типы пропсов всех компонентов. |
| `components/<Компонент>/README.md` | Правила использования каждого компонента. |
| `assets/icons/` | Пять линейных иконок направлений стека (SVG). |
| `assets/logo/` | Логотип behappii в SVG: знак, знак с надписью для светлого и тёмного фона, фавиконка. |

### Подключение на странице

```html
<link rel="stylesheet" href="tokens/tokens.css">
<link rel="stylesheet" href="components/bundle.css">
<script src="https://unpkg.com/react@18.3.1/umd/react.production.min.js"></script>
<script src="https://unpkg.com/react-dom@18.3.1/umd/react-dom.production.min.js"></script>
<script src="components/bundle.js"></script>
```

В SvelteKit или Next.js достаточно `tokens.css` и `bundle.css`: разметку собирайте из классов `.va-*` или переносите компоненты из `bundle.js` в свой проект.
