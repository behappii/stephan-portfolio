# Icon

Линейные иконки 24×24, обводка `currentColor` 1.9 (стрелки 2.4), скруглённые концы. Пять предметных — по одной на направление стека (web, mobile, desktop, infra, design) и две стрелки для кнопок. Без `label` иконка декоративная (`aria-hidden`). Никаких эмодзи и логотипов сторонних технологий: технологию называет тег.
