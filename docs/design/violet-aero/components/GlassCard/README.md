# GlassCard

Стеклянная панель — основа всех карточек: белый градиент сверху вниз (`glass` → `glass-fade`), белая обводка, блик по верхней кромке, размытие фона (`blur-glass`), мягкая фиолетовая тень. Работает только поверх неба или пузырей: на плоском белом стекло не видно. При наведении поднимается на 5px (`lift`).

- `radius="xl"` (24px) для узких карточек, `2xl` (28px) для широких.
- `padding`: `sm` — рамка вокруг поля скриншота, `md` — карточка стека, `lg` — шаг.
