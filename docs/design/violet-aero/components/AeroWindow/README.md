# AeroWindow

Окно в духе Windows Aero для иллюстраций первого экрана: полупрозрачная фиолетовая полоса заголовка с бликом, кнопки управления (последняя — розовая «закрыть»), белая клиентская область. `kind="browser"` добавляет адресную строку. Внутрь кладите скелетные полосы (`lilac`, `lilac-tint`), не настоящий интерфейс. Бейдж `label` называет технологии. Окно декоративное (`aria-hidden`).
