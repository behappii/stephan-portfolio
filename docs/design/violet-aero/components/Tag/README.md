# Tag

Тег технологии (`pearl`) или бейдж платформы (`violet`). Перламутровые теги стоят списком внизу карточки — по одному на технологию, названия как у производителя: SvelteKit, Next.js, React Native, Flutter, Tauri, Docker, Figma. Глянцевый бейдж — одно слово о платформе («Веб», «Мобайл», «Десктоп») в углу поля скриншота или окна-мокапа.
