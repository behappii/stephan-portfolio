# StackCard

Карточка направления стека: плитка-иконка, заголовок, одна строка о том, что это даёт, и теги технологий внизу. Пять карточек в сетке `repeat(auto-fit, minmax(min(210px, 100%), 1fr))` с зазором 18px. Длинные русские слова в заголовке переносите мягким дефисом (`Инфра&shy;структура`) — карточка узкая.
