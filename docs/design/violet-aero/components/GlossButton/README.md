# GlossButton

Глянцевая кнопка-«пилюля» с линией блика посередине — главный приём стиля. **violet** — главное действие, не больше одной на экран («Обсудить проект», «Связаться»). **pearl** — второстепенное рядом с ней («Смотреть проекты») и главное действие на тёмном фоне `dusk`.

- `size="lg"` (58px) на первом экране и в контактах, `md` (44px) в навигации.
- Подпись — глагол в начале, без точки. Стрелка (`icon="arrow-right"`) только у главного действия; `arrow-up-right` — у ссылки, которая уводит наружу (почта).
- Шрифт кнопок тот же, что у заголовков: Nunito 900, межбуквенный −0.01em.
- Подпись white на violet стоит на середине градиента (6–8:1); верхний тон `violet-gloss-top` сам по себе даёт только 4:1, поэтому не делайте кнопку ниже 44px.
- Есть `href` — рендерится `<a>`, иначе `<button type="button">`.
