# Icons

Пять иконок направлений стека из макета: `web.svg`, `mobile.svg`, `desktop.svg`, `infra.svg` (Docker и окружение), `design.svg` (Figma). 24×24, обводка 1.9, скруглённые концы, одна краска — `violet-800` (#4C1D95). В глянцевой плитке перекрашивайте в `on-violet`: удобнее взять компонент `Icon`, он рисует ту же геометрию через `currentColor`.
