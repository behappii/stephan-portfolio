behappii.ru — экспорт портфолио

index.html                     — готовая страница, открывается в любом браузере без сборки.
                                  Шрифты Nunito и Open Sans грузятся из Google Fonts.
assets/logo/favicon.svg        — иконка вкладки (подключена в index.html).
assets/logo/behappii-mark.svg  — знак: глянцевый шар < || />.
assets/logo/behappii-logo.svg  — знак + надпись <behappii.ru/> для светлого фона.
assets/logo/behappii-logo-dark.svg — то же для тёмного фона.

Буквы в SVG переведены в кривые: шрифт для логотипа устанавливать не нужно.

Анимации: пузыри и волна на первом экране, смена карточек при прокрутке
(Chrome, Edge, Safari 26+). В Firefox и при «уменьшить движение» — обычная сетка.

Заглушки в квадратных скобках ([Название проекта], [год], [you@email.com] и т. д.)
нужно заменить перед публикацией. Ссылки GitHub / Telegram / LinkedIn ведут на «#».
